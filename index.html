preflight

OKX.AI · A2MCP

Preflight — the safety gate agents call before they sign

An onchain safety layer built for AI agents. Before an agent spends real money, Preflight answers one question — is this safe — with a single decision instead of a wall of raw JSON to interpret. It returns ALLOW / WARN / BLOCK, a 0–100 risk score, and a human-readable reason, so an agent can actually branch on the result rather than guess. Any critical finding — honeypot, sanctioned counterparty, laundering, fake token — forces a block regardless of the caller's risk tolerance, and missing data is always treated as risk, never as safety.

Ships three tools covering the moments agents actually lose funds: check_token before buying or swapping, check_address before sending funds to a counterparty, and check_approval before every approve/permit call — the most common agent exploit. Stateless service, deployed as a public A2MCP endpoint across eight chains.
