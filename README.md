# Alvin Joe Bridson — Portfolio

A single-page portfolio site. Pure HTML/CSS/JS, no build step, no dependencies to install — just open `index.html` or host the folder as-is.

## Files
- `index.html` — page structure and content
- `style.css` — theme (black / white / grey with a cold accent)
- `script.js` — terminal typing effect, mobile nav toggle

## Before you publish
Search the files for `[ ... ]` and `✎ edit` — these mark placeholder content you should personalize:
- Exact years for both degrees
- Your MSc research title/description
- Real bullet points for each of the three roles
- Issuing body for "Certified AppSec Practitioner"
